INSTALLATION & SAFETY

Know what you're installing.

These are the version 0.5.2 builds for Windows and Android. Keep your device's security protections enabled, and only install files you trust.

Download SHA-256 checksums ↗
How do I install it on Windows?+
Download the .exe installer, review any Windows security prompts, and follow the installation steps. The game installs for your user account and includes an uninstaller. If Windows blocks a file, review its origin and security scan rather than disabling protection.
How do I install the Android APK?+
Download the APK on your Android device and open it. Android may ask whether your browser can install apps from this source. Review the request carefully and keep Play Protect enabled. This is a direct APK download, not a Google Play listing.
What do the checksums tell me?+
A SHA-256 checksum lets you compare your downloaded file with the build provided here. A matching checksum confirms file integrity, not that software is risk-free. Compatibility and security still depend on your device and environment.
What should I know about compatibility?+
The PC package is for Windows x64. The mobile package is for Android, not iOS. Automated game tests were run, but these builds have not been tested on a physical Android device or launched in a native Windows environment. Device-specific issues may still occur.
